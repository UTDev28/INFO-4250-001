ℹ️ How to Read This Graph

This graph visualizes the relationship between users and database tables based on audit log activity.

Green nodes — Database users
Blue nodes — Database tables
Green lines — Normal queries
Orange lines — Privilege changes (GRANT, REVOKE)
Red lines — Destructive ops (DELETE, DROP, TRUNCATE)
Line thickness indicates query volume — thicker edges mean more activity between that user and table.
💡 Look for thick red lines or unexpected connections between low-privilege users and sensitive tables.

    📖 Risk Score Definitions

    pandaBase assigns a risk score (0–100) to every audit event. The score is calculated by combining several weighted factors:

    🗂️ Table Sensitivity

    Every database table has a sensitivity classification. Accessing more sensitive tables adds more risk.

    SensitivityPoints AddedExample Tables
    Critical+25payments, salary_data, credentials, api_keys
    High+15customers, employees, user_roles
    Medium+5orders, audit_log, sessions, config
    Low+0products
    ⚡ Action Type

    Destructive or privilege-changing operations carry substantially more weight than read operations.

    ActionPoints AddedWhy
    DROP / TRUNCATE+50Permanently destroys data or table structure
    GRANT / REVOKE+30Changes access privileges — potential escalation vector
    DELETE+20Removes records; can be used to cover tracks
    UPDATE+5Modifies existing data
    SELECT / INSERT+0Normal read/write operations
    🕐 Time of Access

    Activity outside normal business hours is weighted higher as it may indicate unauthorized access.

    ConditionPoints Added
    Before 6:00 AM or after 10:00 PM+20
    Normal business hours+0
    👤 User Role

    Users in certain roles are scrutinized differently. Lower-privilege or external accounts receive higher scores.

    RolePoints AddedRationale
    External+40Outside the organization — highest risk
    Intern+15Limited authorization — unusual access is suspicious
    DBA / Developer / Analyst / Service+0Expected database access for their role
    📊 Score Interpretation

    The final score is capped at 100. Events are classified into risk tiers:

    Score RangeTierMeaning
    70 – 100CriticalImmediate investigation recommended
    40 – 69HighWarrants attention; review user's recent activity
    20 – 39MediumNote in audit trail; monitor for patterns
    0 – 19LowNormal activity — no action needed
    🏆 Leaderboard

    The Risk Scores leaderboard sums every event's risk score per user. A high total doesn't necessarily mean malicious intent — it can also indicate a user who simply handles a lot of sensitive data. Cross-reference with the anomaly count to distinguish routine high-access users from genuinely suspicious behavior.
